# Business Intelligence Dashboard — Executive Reporting

## Chicago Ride-Share & Municipal Taxi Demand Analysis

This document provides access information and deployment specifications for the interactive Looker Studio executive dashboard connected to the Chicago transit data warehouse.

### Deployment & Data Source Specifications

| Attribute | Specification |
| :--- | :--- |
| **BI Platform** | Looker Studio (Google Cloud) |
| **Data Warehouse** | Google BigQuery (`bigquery-public-data.chicago_taxi_trips`) |
| **Connection Architecture** | Direct Live Query (Dynamic Warehousing Connection) |
| **Production Dashboard URL** | [Looker Studio Executive Report](https://datastudio.google.com/reporting/87045563-9634-4aae-b4be-f237db575605) |
| **Last Verified** | April 2026 |
